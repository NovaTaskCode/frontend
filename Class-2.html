HTML File paths

File Paths specify the location of files. Examples:

  • Absolute path:<img src="https://www.w3schools.com/html/img_girl.jpg">
  • Relative path:<img src="images>/img_girl.jpg"> (assuming images Folder in same directory)
  • Root-relative path: <img src="/html/img_girl.jpg">
