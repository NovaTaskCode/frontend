📝 Key Takeaways

  • <table>- Container for the entire table
  • <tr>- Table row
  • <th>- Table header(bold, centered by default)
  • <td>- Table data cell
  • <caption>- Table title/description
  • <thead>- Groups header rows (semantic)
  • <tbody>- Groups body rows (semantic)
  • <tfoot>- Groups footer rows (semantic)
  • <colspan>- Merges columns
  • <rowspan>- Merges rows
